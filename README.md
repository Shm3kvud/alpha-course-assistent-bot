# Название проекта

Telegram-бот помощник для подбора курсов на платформе «Альфа Курсы» с RAG-системой

## Проблема

На платформе «Альфа Курсы» много курсов, и пользователю сложно быстро понять, какой курс ему нужен. Начинающий предприниматель, например 18-летний пользователь, который хочет открыть табачный магазин, заходит на сайт, видит 106+ курсов и теряется. Ему нужен быстрый и понятный помощник, который задаст уточняющие вопросы и порекомендует подходящее обучение.

## Решение

Мы делаем Telegram-бота-консультанта с RAG-системой. Бот общается с пользователем, задает уточняющие вопросы, учитывает его цель, опыт и сферу бизнеса, а затем рекомендует подходящие курсы на основе базы знаний платформы. Ответ должен быть конкретным, персонализированным и объяснимым: бот не просто дает ссылку, а объясняет, почему курс подходит и что делать дальше.

## Целевая аудитория

- Новички — начинающие предприниматели, которые только хотят открыть бизнес.
- Мидл — предприниматели с опытом, которым нужно развитие или масштабирование.
- Сеньор — опытные предприниматели, которым нужны узкие и продвинутые темы.

## Гипотеза

Если помочь пользователю подобрать курс через Telegram-бота за короткое время, то ему будет комфортнее выбирать обучение, а платформа получит больше целевых переходов и продаж курсов. Бот дает более точные рекомендации, чем обычный каталог, потому что учитывает потребности пользователя и работает с неполными данными.

## Функционал MVP

- Бот задает уточняющие вопросы о сфере, опыте и цели пользователя.
- Бот рекомендует курсы на основе запросов и базы знаний.
- Бот объясняет, почему рекомендует именно этот курс, и предлагает следующий шаг.
- Сохраняется история минимум одного чата.
- Бот периодически отправляет напоминания об обучении.
- Предусмотрены фишки: переключение между чатами / начало нового чата, система аналитики запросов, серии рекомендаций.

## Технический стек

- Python 3.12
- Aiogram
- Модель для эмбеддингов — multilingual-e5-large (fallback e5-small), sentence-transformers
- Текстовая модель — GigaChat / Ollama
- Векторная БД — PGVector
- LangChain-Postgres
- Docker
- Git
